## Simple DCS Plane Status Export

MCU: ESP32-S3 N16R8

Screen: IPS-ILI9488

Network info edit src/network.hpp

Pin map check src/display.hpp

MACH over M1 Red alart.
RALT over 500ft or 150m Red alart.

Support MP,wont brake IC.
